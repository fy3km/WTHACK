# WTHack Demo

A small Android overlay demonstration with a locally generated radar display.

## What it does
- Shows a movable floating panel.
- Draws a demo radar using locally generated points.
- Does not read or modify another app's memory, inspect game entities, automate aiming, or inject touch input.

## Build
The GitHub Actions workflow builds a debug APK on pushes to `main` or when manually started from the Actions tab.
